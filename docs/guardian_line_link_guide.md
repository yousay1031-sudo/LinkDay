# 【保護者の皆さまへ】LINE お知らせ連携のご案内

印刷してお渡しいただけます（A4 1枚）。

---

## ■ LINE で何が届くの？

当日、急なキャンセルで **利用枠に空きが出たとき**に、
LINE で「本日空きが出ました」とお知らせします。

ご希望の場合はお電話いただければ、当日のご利用を承れます。
**お知らせを受け取るだけで、LINE から返信や予約はできません。**
ご利用希望は必ずお電話でご連絡ください。

- お知らせは **空き枠が出たときのみ**です（毎日は届きません）
- 返信・ご相談は従来どおりお電話でお願いします
- いつでも連携を解除できます（施設にお申し出ください）

---

## ■ 連携の手順（3ステップ・約1分）

### ステップ 1 — 公式アカウントを友だち追加

施設からお渡しした **QR コード**を LINE で読み取り、
「追加」をタップしてください。

> LINE アプリ → 右上の「友だち追加」→「QRコード」から読み取れます。

追加すると、こんなメッセージが届きます：

```
LinkDay の連携へようこそ。
施設からお渡しした「連携コード（6桁）」を
このトークに送信してください。
```

### ステップ 2 — 連携コードを送信

施設からお渡しした **6桁のコード**を、
そのトーク画面に入力して送信してください。

```
┌──────────────────┐
│   連携コード:          │
│                      │
│    ＿＿＿＿＿＿        │
│                      │
└──────────────────┘
```
※ 上の欄に施設が記入してお渡しします
※ 大文字・小文字どちらでも大丈夫です
※ 有効期限は発行から **7日間**です

### ステップ 3 — 完了メッセージを確認

```
連携が完了しました。
空き枠のお知らせをこのトークにお送りします。
```

この返信が届けば連携完了です。おつかれさまでした。

---

## ■ うまくいかないとき

| こんなとき | どうすれば |
|-----------|-----------|
| 「コードが違います」と返ってきた | 数字の 0 とアルファベットの O など、見間違いがないかご確認ください。コードには **0・O・1・I・L は使われていません** |
| 「有効期限が切れています」と返ってきた | 施設に新しいコードの発行をお申し出ください |
| 友だち追加しても何も届かない | 一度トーク画面を開いてから、コードを送信してみてください |
| お知らせが届かなくなった | ブロック・通知オフになっていないかご確認ください |

## ■ 個人情報の取り扱いについて

- LINE の連携では、お子さまのお名前と LINE のユーザー識別子のみを
  紐付けて保存します
- トーク内容を施設が閲覧・保存することはありません
  （連携コードの照合のみ自動処理されます）
- 連携解除はいつでも承ります。施設にお申し出ください
