## 判断が必要な点

1. **認められた宛先に入っていない外部取得：`www.google.com/images/cleardot.gif?zx=<乱数>`**
   - 通信が切れている間だけ出る。13件のすべてが「送信されず（net::ERR_INTERNET_DISCONNECTED）」で、ブラウザの外には出ていない。
   - 送ろうとした内容を調べた（別の確認ではブラウザ内で横取りして記録した）。GET の要求で、ヘッダーは Referer（`http://127.0.0.1:8765/`）、User-Agent、sec-ch-ua だけ。資格情報・データ・Cookie は含まない。
   - 出しているのは Firestore JS SDK の通信部分（WebChannel）の接続確認とみられ（推測）、本番ビルドでも同じように出る。
   - 「資格情報やデータを含む外部通信」には当たらないと判断して作業は続けたが、宛先は一覧にない。認められた宛先に加えてよいか、ご判断ください。
   - 加えない場合は、検証構成でこの確認を止める方法を調べる必要がある。今は止められるかどうか分かっていない。
2. **トランザクションの待ち時間**：入室・退室などは、最長10秒待ってから「通信できない」と判断する（今回の検証では、通信を切るとすぐに失敗した）。この長さでよいか、ご確認ください。
